# NAI Studio 发布与更新

本仓库仅用于发布 NAI Studio 的 Windows、Android 安装包、版本说明及校验信息。源码单独保存在私有仓库中。

## 下载

请前往 [Releases](https://github.com/zzz123780/nai-studio-releases/releases) 下载正式版本。

- Windows：`NAI-Studio-Setup-版本号.exe`（安装版）或 `NAI-Studio-版本号.exe`（便携版，以实际资产名称为准）。
- Android：`NAI-Studio-Android-版本号-debug.apk`。

从 0.1.8 起，应用设置中提供检查更新、下载安装包和安装更新入口。下载完成后会核对安装包大小与 GitHub 提供的 SHA-256 摘要，安装仍需用户确认。

仓库不接收账户 Token、生成图片或用户数据。
